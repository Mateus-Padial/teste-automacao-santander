# 🧪 Projeto de Automação de Testes – Cypress + Cucumber + Page Objects

Este repositório contém uma suíte de testes automatizados para validação de fluxos WEB e API, utilizando:

- **Cypress 13+**
- **Cucumber (BDD)**
- **Page Object Model (POM)**
- **Esbuild Preprocessor**
- **Variáveis de ambiente via .env**

## 🚀 **1. Como instalar o projeto**

### **Pré-requisitos**

- Node.js **18 ou superior**
- NPM ou Yarn
- Git instalado

### **1. Clonar o repositório**

```bash
git clone https://github.com/Mateus-Padial/teste-automacao-santander.git

```

### **2. Instalar dependencias**

```bash
npm install
```
